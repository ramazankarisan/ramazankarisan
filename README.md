## 🚀 About me

Software developer in Berlin with a focus on frontend and AI. Since 2022 I've been building React and TypeScript apps for enterprise clients in automotive, vehicle inspection and data privacy, plus security tooling and civic tech. I care about software that holds up under real use: typed, tested, and easy for the next person to change.

- 🤖 AI-assisted, agentic development is my daily workflow, and I'm growing into building LLM features into web apps
- 🏅 Claude Certified Architect (Foundations) and iSAQB CPSA-F software architecture certified
- ⚛️ Currently contributing to [ThreatSea](https://github.com/MaibornWolff/ThreatSea), an open-source threat-modeling tool (React + TypeScript)
- 🧪 Took test coverage from zero to 80%+ on a production platform
